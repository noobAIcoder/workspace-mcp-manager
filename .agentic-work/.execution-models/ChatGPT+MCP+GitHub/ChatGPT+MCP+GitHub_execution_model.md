# ChatGPT + MCP + GitHub Execution Model

ChatGPT performs workspace and runtime operations through MCP and repository operations through GitHub.

## Allocation

* ChatGPT: analysis, planning, specification work, review, and coordination.
* MCP: workspace and runtime access for ChatGPT.
* GitHub: repository inspection, modification, and delivery for ChatGPT.
* Operator: human-only or otherwise unavailable operations.

Unavailable MCP or GitHub capability blocks the dependent execution path without changing the active Execution Model.
