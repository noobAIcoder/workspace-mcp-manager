# ChatGPT + GitHub Execution Model

ChatGPT performs repository work through GitHub. Target-side execution unavailable to ChatGPT is performed by the operator.

## Allocation

* ChatGPT: analysis, planning, specification work, review, and repository changes.
* GitHub: repository inspection, modification, and delivery for ChatGPT.
* Operator: target runtime, hardware, or integration execution unavailable to ChatGPT.

## Target-side handoff

ChatGPT supplies the repository revision, environment, working directory, required actions or commands, and expected observations.

Unavailable target-side capability does not change the active Execution Model.
