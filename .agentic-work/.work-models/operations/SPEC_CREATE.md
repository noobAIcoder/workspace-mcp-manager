# Specification Creation

## Contract

Specialize the [SDD stage](../profiles/SDD.md) for required authority that does not yet exist, within the [SDD/TDD lifecycle](../flows/SDD_TDD.md). Inputs are the validated end result, specification-creation deltas, governing requirements, and selected artifact contracts.

## Creation Responsibilities

Use the selected specification framework's owning templates, document graph, materialization, and readiness rules.

Without an enclosed framework, the candidate MUST define objective, scope, constraints, normative behavior, failure conditions, and verifiable acceptance criteria sufficient for independent implementation.

New authority MUST have an identified owner and MUST NOT duplicate an existing contract. Where creation also affects existing specifications, include those consequences in the same SDD record.

## Output and Exit

Supply the new candidate and creation-delta disposition. Validation, acceptance, no-op behavior, and stage completion are owned by SDD; blocking and subsequent stages are owned by the lifecycle.
